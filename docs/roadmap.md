# Menuza Roadmap

## Phase 1: Runnable MVP

- Monorepo foundation.
- Dashboard shell.
- Mobile ordering shell.
- Express microservices with in-memory contracts.
- Central language model and translation placeholder.

## Phase 2: Production Data

- PostgreSQL schemas per bounded context.
- Prisma or Drizzle migrations.
- JWT sessions and refresh tokens.
- Tenant-aware authorization middleware.
- Restaurant onboarding workflow.

## Phase 3: Ordering Operations

- Cart persistence.
- Order status events.
- Kitchen display view.
- Staff assignment.
- Notifications.

## Phase 4: Translation Platform

- Translation memory.
- Human override workflow.
- Provider integration.
- Menu localization quality checks.
- Audit history for translated order notes.

## Phase 5: Commercial Layer

- Accounting dashboard.
- Restaurant billing.
- Platform revenue reports.
- Owner-level analytics.
